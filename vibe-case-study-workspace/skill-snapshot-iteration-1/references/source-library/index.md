# Case-Study Source Library

Use this index after the evidence map and archetype are stable. Source patterns can suggest questions, causal structures, candidate statements, and proof treatments. They cannot supply facts for the current project.

## Pattern-card contract

Every card must include:

```text
Pattern ID and name:
Source and access date:
Original narrative signal:
Transferable interpretation:
Applicable archetypes:
Required project evidence:
Candidate question:
Adapted-statement formula:
Factual risks:
Suitable visual or proof treatment:
```

## Candidate status

- **Observed:** supported by repository, product, artifact, or independently inspectable evidence.
- **Author-reported:** supplied by the author but not independently visible; request a receipt where practical.
- **Hypothesis:** usable only as a next signal, success criterion, or question.
- **Unsupported:** exclude from the public article.

Retrieve one to three cards per case. Record the pattern IDs and resulting candidate statements in production notes.
